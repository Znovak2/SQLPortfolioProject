# Definitions Page Overview
This file/page contains definitions or important distinctions which show a true understanding of concepts and/or topics.

## Definitions
- <u>SCALAR</u> - A single value, such as '10','John', or the results of a calculation like '5+3'.
- <u>EXPRESSION</u> - A combination of values, columns, functions, and operators that SQL evaluates to produce a result.
- <u>Comparison of 'Operator' and 'Operant'</u> - An operator performs an action, such as +, =, or >, while an operand is the value or expression the operator acts on.
- <u>Table valued expression</u> - a table-valued function is a user-defined function that returns multiple rows as a table.
